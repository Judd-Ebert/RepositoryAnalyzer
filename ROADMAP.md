# Roadmap

## Working on now

- Wiring up live ingestion status from the backend to the frontend
- Building a simple polling flow for job progress
- Cleaning up the onboarding and landing page experience

## Near term

- Add a dedicated job-status endpoint and make the UI react to it
- Improve provider/model validation so OpenAI and Ollama behave more predictably
- Strengthen API key storage and validation

## Medium term

- Support mixed provider usage, such as OpenAI embeddings with Ollama chat
- Improve the query experience and result presentation
- Harden error states and retries for failed imports
